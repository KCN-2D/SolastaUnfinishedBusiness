# Solasta Unfinished Business カスタム版

[Solasta Unfinished Business](https://github.com/EnderWiggin/SolastaUnfinishedBusiness)をもとに、フレンドとのマルチプレイ向けに調整したカスタム版です。

## 必要なもの

- Solasta: Crown of the Magister
- [Unity Mod Manager](https://www.nexusmods.com/site/mods/21) 0.33.2
- カスタム版の `SolastaUnfinishedBusiness.zip`

## 導入手順

1. Unity Mod Managerの配布ページでNexus Modsにログインし、`Files`から`Manual Download`を選びます。
2. ダウンロードしたファイルを展開し、`UnityModManager.exe`を起動します。
3. ゲームの一覧から`Solasta`を選び、Solastaのインストール先を指定します。
4. `Install`を押します。
5. `Mods`画面を開き、`SolastaUnfinishedBusiness.zip`をドラッグします。
6. Solastaを起動し、Unity Mod Managerの画面で`SolastaUnfinishedBusiness`が有効になっていることを確認します。

インストール先は、SteamのライブラリでSolastaを右クリックし、`管理`→`ローカルファイルを閲覧`から確認できます。

## 更新手順

Solastaを終了し、Unity Mod Managerの`Mods`画面へ新しい`SolastaUnfinishedBusiness.zip`をドラッグします。

旧版の`Mods/SolastaUnfinishedBusiness/BlenderModels/CharacterFaces`フォルダーがゲームのインストール先に残っている場合は削除します。

Unity Mod Manager本体を更新したときは、ゲーム一覧でSolastaを選び、ゲームに導入済みのUnity Mod Managerも更新してください。
